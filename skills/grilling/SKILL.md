# Grilling

Interview the user relentlessly until you reach a shared understanding.

## How it works

Work in **rounds**. Each round, ask all questions that can be answered NOW (the frontier). Wait for answers before the next round.

## Format

```
❓ **Q1** - **<question title>**: <question body>

➡️ <your recommended answer>

---

❓ **Q2** - **<question title>**: <question body>

➡️ <your recommended answer>
```

## Rules

1. Word each question so "yes" accepts your recommendation
2. Finding facts is YOUR job (use tools), decisions are the USER's job
3. Done when frontier is empty — nothing left assumed
4. Don't act until user confirms shared understanding
